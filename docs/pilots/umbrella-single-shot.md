| 项目 | 本单提议 |
| --- | --- |
| scene / replicate | `software_bus_stop` / 1；保留software命名和来源，不改成正式样本 |
| 原镜头 | `return-umbrella`，完整计划原索引0，4秒 |
| 事件/景别 | 中景双人镜头：林递出收拢的伞，博接过；同时看到手和脸 |

| 版本 | `baseline`、`generic_review`、`moodcut`，每个一段4秒视频，共三段、12个输出视频秒，最多3个新POST |

选择理由：已有完整1.1软件源、明确的手部交接动作、单一说话人和三种不同台词，能以小范围检验接口及声音；4秒是本候选原时长，不人为裁短故事或增加镜头。它是已用过的开发故事，不是新数据集或盲测样本。

| 设置 | 三版本共同值 |
| --- | --- |
| model / 目录slug | `bytedance/seedance-2.0-mini` / `bytedance/seedance-2.0-mini-20260811`；请求使用model ID，slug用于快照记录，不保证服务端权重永远固定 |
| resolution / size / ratio | `720p` / 1280×720 / `16:9` |

| 风格 | 连续电影感实拍风格、雨天公交站；自然交接、共同服装/身份、手与脸可见；无标题卡、拼贴、字幕/标签 |

完整style、sound和voice字符串保存在候选清单，跨三个版本完全一致；只将各自dialogue替换到同一P4模板。固定seed不保证改台词后的画面、口型或表情相同。900秒是客户端轮询时限，不是提供商生成时长保证，也不包含所有下载/HTTP等待；三个任务仅轮询部分的配置时限可累计45分钟，首次操作须预留人工观察窗口，超时后停止而不补交。

## 4. 完整预算与费用核对

币种USD。2026-10-23只读取未认证的公开模型目录/网页，没有生成请求或密钥余额查询。Seedance图像参考＋原生声音报价为$3.50/百万输出视频token；按原报价函数的 `宽×高×秒×24/1024` 计算。24是计价公式系数，不宣称生成文件一定为24fps。

```text
每段视频token = 1280 × 720 × 4 × 24 / 1024 = 86,400
每段本地报价  = 86,400 × 3.50 / 1,000,000 = $0.3024000
三段本地报价  = 3 × 0.3024000 = $0.9072000
```

| 费用组成 | 首选固定输入试跑 | 口径/停止条件 |
| --- | --- | --- |
| 新文本规划 | $0，0次 | 复用明确手写的完整共同计划，不新增文本调用；不是“真实P2结果免费” |
| 新通用/情绪审查 | $0，0次 | 复用本表手写版本，不给它们编造真实调用或消费 |
| baseline / generic_review / moodcut视频 | 各报价$0.3024，共$0.9072 | 三个请求指纹不同，预算不预扣复用优惠；失败仍保留实际费用，报价不是usage.cost |
| 视频客户端提议阈值 | $1.00 | 含$0.0928报价余量；初始正常轮询与首次内容下载属于该视频执行流程，不另编一个GET单价 |
| 额外恢复/异常预留 | $0.10，默认未授权使用 | 仅供后续单独核准的异常处理；不是GET单价/免费证明，不等于client.resume的代码硬上限，不购买替代视频POST |
| 首选新增支出提议额度 | **$1.10** | $1.00视频阶段＋$0.10锁定备用；无新文本，当前没有批准其中任何一项 |
| 本轮文档/软件核对 | **实际新增$0** | 无付费API、实际视频任务、GPU、模型下载或主观评分 |

公开目录仅列视频token SKU，未给出单独轮询/下载按次费，不据此断言GET免费。启动前须核对完整收费条款、当前余额和平台费用限制；如果存在未覆盖附加费，先更新预算并重新批准。额外人工GET-only恢复默认不包含在批准中，不能拿“已经预留$0.10”代替授权。恢复后使用同一任务的最新完整消费，不把累计usage每次再加一次；未知仍为null，停止所有后续提交。

本地 `--max-cost-usd` 是单客户端估算阈值，不能保证提供商实际消费不会超过报价，也不是跨进程共享账户硬额度。运行负责人应另外确认平台侧给本单分配的余额/限制；不同客户端不能各花一次$1.10。剩余预算不自动转给重试、新镜头、切换模型、正式样本或下次运行。
