# S09 v2（探索性第二版）修改草稿

> **状态：草稿，未生成视频，未被团队采纳。**
> **性质：探索性第二版。** 它不替换 S09 v1，不进入 S07–S12 的正式结果；v1 的三条视频和结果原样保留。
> 本草稿的依据是 `scene.json` 的文字和人工观察（"S09 的恐惧很难识别"），**撰写时没有查看 S09 的视频内容**，"画面缺少恐惧线索"是推断，需要在生成前由人工核对 v1 视频。

## 1. 为什么只改 S09

| 故事 | 人工判断 | 原因 | 是否改提示词 |
|---|---|---|---|
| S10 喜悦 | 喜悦明显，但与惊讶分不开 | 测量局限（VEMOCLAP 的 joy 几乎不输出，画面易读成 surprise） | 不改 |
| S12 惊讶 | 读不出悲伤（模型判悲伤 48%） | 测量错误；且三个条件是同一个文件，无法比较 | 不改 |
| S09 恐惧 | 很难识别 | 疑似生成问题：v1 的剧本边界禁止了几乎所有可见的恐惧线索 | **改（本草稿）** |

## 2. v1 的限制（来自现有 `scene.json`）

- 补充边界：不展示生物、额外人物、武器、袭击、受伤或逃脱结果。
- 另有：不尖叫、奔跑、夸张发抖、施法或制造突然惊吓。
- 两句对白的核心是"承认自己害怕"（Elsa）和"危险不明，我也害怕"（Mattias）。

结果是恐惧几乎只能靠两句话传达，画面和语气上没有可见线索；而恐惧又依赖场景（未知的威胁），不看场景很难单独读出。

## 3. v2 要改什么（只改一个因素：把恐惧"表达得出来"）

### 3.1 放宽的限制（允许很小的、克制的身体反应）

允许：睁大眼睛、目光盯住同一个方向、屏住呼吸、下意识后退半步、下意识抓住对方的衣袖或手臂、声音压低、说话中出现短暂停顿。

仍然禁止（与 v1 相同）：尖叫、奔跑、夸张发抖、施法、突然惊吓；展示生物、额外人物、武器、袭击、受伤或逃脱结果。

### 3.2 对白指导（具体化，但不直接说情绪标签词）

- Elsa：用带身体感受的方式表达不安，例如声音压低、语句短促，并指出听到的动静正在靠近。
- Mattias：用不确定的问句或压低的回应，说明不知道那是什么，并表示自己同样不安。
- 不得直接念出"愤怒、厌恶、恐惧、喜悦、悲伤、惊讶"这六个标签词（沿用 v1 规则）。是否使用"害怕"这类日常词，沿用 v1 的写法，不再扩大。
- 具体措辞仍由规划 Agent 生成，不在本草稿中固定台词。

### 3.3 建议替换的 `story` 补充边界（草稿文字，待审阅）

把 v1 的

> 本场景补充边界：不展示生物、额外人物、武器、袭击、受伤或逃脱结果。 不尖叫、奔跑、夸张发抖、施法或制造突然惊吓。

替换为

> 本场景补充边界：不展示生物、额外人物、武器、袭击、受伤或逃脱结果；不尖叫、奔跑、夸张发抖、施法或制造突然惊吓。允许克制的可见不安：两人睁大眼睛、盯着同一方向、屏住呼吸、下意识后退半步或抓住对方衣袖，声音压低、语句短促并有短暂停顿。

`beats` 可保持 v1 原文，不新增节拍：

1. Elsa承认自己害怕正在接近的未知生物。
2. Mattias回应危险尚不明确，并承认自己也害怕。

其余字段（角色、`asset_ids`、`min/max_duration_s = 5`、单镜头、语言）保持不变。

## 5. 评测与解读（生成前先定下）

- 人工：六类情绪加"不确定"，不确定算识别失败；先盲看再对照。记录是否被判成 fear 以外的类别，**混淆对本身就是结果**。
- VEMOCLAP：保留六类概率，不合并类别。
- 预期之外的结果同样记录：v2 的 fear 若仍然很低，说明 VEMOCLAP 在这类动画上基本测不出恐惧，应改为只用人工评分，**不继续改提示词去凑指标**。
- v2 与 v1 的差异只能说明"放宽限制后的变化"，不能说明对白修改的效果，因为 v1 与 v2 的初稿不同。三个条件之间的比较只在 v2 内部有效。
