# 氛围名词与 VEMOCLAP 证据对应：修订草案（DRAFT）

草案日期：2026-10-25。本文件是草案，尚未被团队采纳；是否合入由团队决定。

## 1. 为什么要修订

- 当前六故事 v2 使用三种氛围：亲密（affectionate）、敌对（hostile）、紧张（tense）。VEMOCLAP 只输出六类基本情绪（anger、disgust、fear、joy、sadness、surprise），没有“亲密”对应类别。
- 在 12 个预试视频（6 个真人电影片段、6 个项目动画视频）上，亲密场景几乎不出现 joy，多数落在 sadness 或 surprise；敌对大体落在 anger／disgust，紧张落在 fear。
- 本修订的动机来自 VEMOCLAP 预试，**不是**来自方法比较（baseline／generic_review／moodcut）的胜负，**不改变**任何故事、剧本、人物、条件或评分流程。

## 2. 修订内容

| 项目 | 现状 | 修订后 |
|---|---|---|
| 数据与解析中的内部标识 | affectionate／hostile／tense | **不变**（避免破坏评分解析器与哈希） |
| 展示名 | 亲密 | 温情（亲密、陪伴） |
| VEMOCLAP 证据：hostile | 未定义 | anger ＋ disgust |
| VEMOCLAP 证据：tense | 未定义 | fear |
| VEMOCLAP 证据：affectionate | 未定义 | sadness ＋ joy |
| surprise | 未定义 | 不作为任一氛围的证据；surprise ≥ 50% 时该视频记为“无法判定” |

判定办法：对每个视频，计算三个氛围的分数（上表各类概率之和），取最高者为 VEMOCLAP 的氛围读数；surprise ≥ 50% 的视频不判定，且不计入命中或未命中，但必须在报告中单独列出弃判数。

## 3. 使用边界（必须随结果披露）

1. VEMOCLAP 只是辅助诊断，不替代人工评分，不用于方法排名。
2. “温情”的证据（sadness＋joy）只说明“没有敌意或恐惧”，**不能**与一般的悲伤区分，也不能证明亲密。
3. 音频是最大的决定因素：预试中把一条视频后 5 秒的背景音乐静音，结果从 sadness 96.4% 变成 anger 56.3%。三个条件的音轨必须一致（例如都不含背景音乐，或评测前统一处理），否则差异可能只来自音乐。
4. 动画视频出现过 surprise 偏高（S01 v4 baseline 83.7%、actor-v1 96.1%），已由弃判规则处理，但原因未查明。
5. 同一视频重复运行结果完全一致（已在 CPU 离线流程验证），但换机器或软件版本未验证。

## 4. 冻结与验证

- 规则冻结文件：`frozen_rule.json`（含 SHA-256）。在跑 6 个新视频之前冻结，之后不得按这 6 个视频的结果调整。
- 验证集：6 个未用于制定规则的真人对话片段，每种氛围 2 个（见 `validation_clips.md`）。
- 通过标准（事先固定）：可判定的视频中命中 ≥ 5/6；弃判 ≤ 2；每种氛围至少命中 1 个。
- 未通过：不采用本映射，只保留人工评分，或回到名词设计重新讨论。
- 通过也只说明规则在这批真人老电影上自洽，不证明它适用于你们的动画视频。

## 5. 已知限制

- 预试只有 12 个视频，紧张只有 2 个，且都来自恐怖片；映射规则是看过数据后设计的，存在过拟合。
- 验证片段来自黑白或旧画质老电影，与动画五秒视频差别很大，且部分片段含多人（非严格两人）。
- 验证片段与预试片段来自同样的几部影片，不是完全独立。
- 视频的公有领域标注来自 archive.org 上传者，仅作内部分析，不再发布。

## 6. 需要团队确认

- 展示名“温情”是否采用，还是保持“亲密”并仅在 VEMOCLAP 一侧改证据说明。
- 弃判阈值（surprise ≥ 50%）和通过标准是否接受。
- 是否把本修订写入协议（标明动机来自预试、未改故事）。
